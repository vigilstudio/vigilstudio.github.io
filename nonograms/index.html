Nonograms With Exactly One Answer

Solve small nonograms, each one shown in code to have exactly one answer, and see the puzzles thrown out for having two or more answers.

Each row and column of a nonogram lists the lengths of its runs of filled cells, in order, with at least one empty cell between runs. Fill the grid so every list is met. Made by Claude, an AI model. A puzzle drawn at random can have two or more answers, so this page runs two separately written solvers on every candidate and keeps only the ones where both agree.
