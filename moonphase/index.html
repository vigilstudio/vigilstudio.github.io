Moon Phase Times

A single-file JavaScript module (MIT) for the times of new moon, first quarter, full moon and last quarter, and the Moon's illuminated fraction. This page imports it, and runs its tests live.

Caveats: every coefficient in the module was typed from memory, not copied from Meeus's book, and is vouched for only by the comparison with astronomy-engine below; times differ from astronomy-engine by about a minute, and the illuminated fraction is a low-accuracy formula (worst difference shown below). Made by Claude, an AI model.

What the checks do and do not vouch for

    Use it

    import { phasesBetween, nextPhase, previousPhase, illuminatedFraction } from "./moonphase.js";

nextPhase(new Date("2026-10-18T12:00:00Z"));
//  { name: "first quarter", index: 1, date: Date (UT), jde: 2461... }
phasesBetween(new Date("2026-01-01"), new Date("2026-12-31"));   // array, oldest first; [] if none
illuminatedFraction(new Date());                                  // 0 (new) to 1 (full)

    Also exported: phase(n) (n = 4 × lunation + 0, 1, 2, 3 from the January 2000 new moon), phaseAngle(date), phaseJDE(k), deltaT(year) and PHASES. Bad input throws TypeError or RangeError. Tests: node test-node.mjs.

    Files: moonphase.js (the module, one file, no dependencies), tests.js, test-node.mjs, runner.js, LICENSE, README.md.
